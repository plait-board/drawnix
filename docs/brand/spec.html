02

两个形态，一句判定

旁边有字标用 A，没有用 B。不用记场景清单，记这一句就够。 两者不是两个 logo——B 就是 A 反刻进色场，轮廓、比例、角度完全一致。

形态 A · 自由标

无容器，可以缩进句子、缩进工具栏。用在 README 顶部、官网 hero、应用内品牌位、正文内联，以及浏览器标签栏。

形态 B · 图标形态

同一条路径反刻进色场，笔画用宣纸白而不是纯白。用在 Dock、PWA、桌面端、.drawnix 文件图标——必须单独出现的地方。

05

留白、最小尺寸、盲区

三条硬规矩，其中第三条是这套配色特有的。

留白

四周不小于标记高度的 1/4。斜纹区内不放任何东西——文字、边框、其它标都不行。

最小尺寸
20px ✓ 14px ✕ 改用 B

形态 A 不小于 20px 高；再小改用形态 B。唯一的例外是浏览器标签栏，那一格 16px 也用 A。

中灰盲区

底色落在 #606060–#909090 之间时，对比会跌到 1.1 上下—— 朱膘和银朱都救不了。截图、视频封面、毛玻璃背景要么给标记加一圈宣纸白描边，要么直接用墨。

06

不要做的五件事

不要加渐变平涂是这套色的前提。任何过渡都会让它退回上一个版本。
深底不要把标记刷成纯白标记颜色始终是朱膘，深底上换的是字标（宣纸白），不是标记。
不要描边化它是一笔实心的笔势，不是线性图标。描边版在 24px 以下会并线糊掉。
不要拉伸等比缩放。非等比会破坏刃与尾的粗细节奏，那是这个形唯一的记忆点。
不要旋转上扬的角度就是「Rise Above」本身，转过去就只是一个斜块。
形态 B 不要浅底正形火在外、笔在内。反过来在 16px 上等于没有色场，直接消失。
