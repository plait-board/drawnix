# 品牌页

两份自包含的 HTML，双击即可在浏览器打开，无外部依赖、无网络请求。

| 文件 | 内容 |
|---|---|
| `spec.html` | 落地规范：三个色值、两个形态、图标全套真实尺寸、六个真实场景、留白与禁则、文件清单 |
| `motion.html` | 动效规范：擦除机制、四个动作（页内实时播放）、六秒社媒序列、画幅与安全区、出片命令 |

## 两个比例常数

整套 lockup 只由两个数决定，改一个三处一起动：

```
标记高 = cap × 1.62
间距   = cap × 0.36
```

`cap` 是字标 D 的大写字高。生成脚本 `scripts/build-brand.py` 按这两条算，
两份页面的 CSS 也从同一个 `--cap` 变量推导，不再各写各的。

## 重新生成

品牌资产（`apps/web/public/brand/`）：

```sh
python3 scripts/build-brand.py
```

改了 `MARK` 路径或色值就重跑，尺寸与锚点是联动的，不要手改导出物。
这两份页面是手工维护的，改完记得同步页面里内嵌的几何数值。
