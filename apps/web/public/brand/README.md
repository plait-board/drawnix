# Drawnix 品牌物料

标志由一道**挑势**（起笔蓄力的弧）带出一支**上扬的羽尾**构成。
一笔既是白板上落下的第一笔（*Draw*），收笔的分叉即凤凰的尾翎（*Phoenix*）。

## 两个形态

| | 形态 A · 自由标 | 形态 B · 图标形态 |
|---|---|---|
| 长什么样 | 标记本身，无容器 | 同一个形反刻进圆角色场 |
| 用在哪 | 旁边**有字标**的场合 | 需要**单独出现**的场合 |
| 为什么 | 无容器，能缩进句子、缩进工具栏 | 16px 上只剩颜色可辨，必须有色场 |

**判定规则只有一条：这次露出旁边有没有字标。有，用 A；没有，用 B。**

两者不是两个 logo——B 就是 A 反刻进色场，轮廓、比例、角度完全一致。

## 文件

### 标记与组合
| 文件 | 用途 |
|---|---|
| `mark.svg` | 形态 A，渐变 |
| `mark-mono.svg` | 形态 A，单色（`currentColor`，随文字颜色走） |
| `logo-h.svg` / `logo-h-dark.svg` | 横版组合，浅底 / 深底 |
| `logo-h-mono.svg` | 横版组合，全单色 |
| `logo-v.svg` / `logo-v-dark.svg` | 竖版组合 |

### 图标
| 文件 | 用途 | 标记占比 |
|---|---|---|
| `icon.svg` | 通用图标（圆角） | 0.74 |
| `icon-square.svg` | 满幅方版，供 apple-touch-icon 派生 | 0.68 |
| `icon-maskable.svg` | PWA maskable | 0.615 |
| `icon-solid.svg` | 单色场备用，更冷静 | 0.74 |

**满幅方版和 maskable 版必须留满边、不带透明角**——这两类图标由系统自己切角，
自带圆角会在部分启动器上露出缺角。maskable 的 0.615 是按安全区（中心 80% 直径圆）反推的上限。

## 颜色

```
冷  #2f6bff   结构 —— 流程图、思维导图
中  #7b5bf2
暖  #ff5e3a   创造 —— 自由画、凤凰
墨  #050928   字标
```

渐变自左下（冷）至右上（暖），与标记的运笔方向一致。

## 用法约束

- **留白**：四周留出不小于标记高度 1/4 的空白。
- **最小尺寸**：形态 A 不小于 20px 高；再小改用形态 B。
- **深色底**：用 `-dark` 版本，标记保持渐变——不要整体换成纯白，渐变是最强的记忆点。
- **不要**旋转、拉伸、换渐变角度、加描边、加阴影，或往标记上挂任何附加符号。

## 关于字标：不做定制

字标沿用旧版字形。曾计划做字形定制让它与标记共享曲率，四种改法都试过并逐一否掉：

| 改法 | 结果 |
|---|---|
| `x` 终端改斜切 | 幅度小时使用尺寸下看不见；大到能看见时，`x` 变成星芒 |
| `D` 碗外缘加直边 | 这个字体的 `D` 本来就近乎直边，加了没有可见变化 |
| 整体收紧字距 | `r`/`a` 原本只有 2 单位间距，一收就粘连 |
| `i` 点倾斜 29° | 使用尺寸下几乎不可辨；转到 45° 就成了装饰性的菱形 |

原因是这个字体**本来就和标记共享同一套语汇**——几何骨架、近直的碗、干净的平切端，
而且现有字距已经是按视觉调过的（直-直配对间距大、`r`/`a` 这种开口配对间距小），不是均匀字距。

**定制在这里是在解一个不存在的问题。** 字标保持原样。

全部物料由 `scripts/build-brand.py` 生成（需要 `rsvg-convert`）：

```bash
python3 scripts/build-brand.py
```

改动请改脚本后重新出全套，不要手改单个文件——标记路径、缩放锚点和各尺寸之间是联动的。
